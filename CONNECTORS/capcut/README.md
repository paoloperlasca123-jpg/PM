# Conector: CapCut

**Estado:** sin API oficial.

CapCut no publica una API ni SDK de terceros para automatizar
proyectos (importación de clips, timeline, exportación). No se
simula ni se fuerza ninguna integración directa — eso violaría los
términos de servicio.

## Lo que sí se automatiza

Todo lo que rodea a CapCut, no lo que ocurre dentro de la app:

- Dejar `04_EDICION` del proyecto con el RAW, B-roll, recursos y
  subtítulos generados (`.srt`), ya nombrados y organizados, listos
  para importar manualmente.
- Una vez que el usuario exporta el video desde CapCut, moverlo a
  `05_FINAL` (con confirmación).

## Si en el futuro CapCut publica una API

Se agregaría aquí como automatización adicional, documentando el
alcance real que permita esa API — nunca antes de que exista.
