# Conector: TikTok

**Estado:** no configurado.

## API oficial

Existe (TikTok API for Developers, incluye Content Posting API),
pero el acceso a las funciones de publicación/métricas está sujeto
a revisión y aprobación de la app por parte de TikTok — no es un
alta inmediata como Gmail o Slack.

## Automatizaciones posibles (si se aprueba el acceso)

- Publicación directa de un video finalizado.
- Traer métricas del post hacia el `manifest.json`.

Hasta no tener la app aprobada, la publicación en TikTok sigue
siendo manual. No se activa hasta que se configure explícitamente.
